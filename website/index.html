Built for a day of focused work

The timer, the queue, and the history all read from the same local database, so nothing drifts out of sync.

Focus timer

Work and break sessions alternate automatically, with distinct cues for starting, pausing, and resuming.

Today queue

One committed list for the day: add, reorder, complete, and undo. Anything due but not queued is surfaced for you.

Recurring tasks

Daily, weekly, or every-N-days rules. Each occurrence is tracked separately, so finishing Tuesday's does not erase Wednesday's.

Projects & notes

Group tasks into colour-coded projects, each with its own scratchpad that saves as you type.

Stats & streaks

Daily focus totals, cycle averages, and a work streak that only counts completed focus sessions.

Shortcut & tray

Start, pause, or skip from the system tray, or bind a global shortcut. The window hides instead of quitting so the timer keeps running.

Your data never leaves your machine

Flano has no account system and no server component. Sessions, tasks, and settings live in a single app.db SQLite file you can back up yourself.

✓ No account. Nothing to sign up for or sign in to.

✓ Works offline. Timers, tasks, and stats run with the cable unplugged.
